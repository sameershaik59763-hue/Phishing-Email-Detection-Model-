# Phishing Email Detection Model

## 📌 Description
This project uses Machine Learning to classify emails as Phishing or Safe.

## 🚀 Features
- Text preprocessing
- TF-IDF feature extraction
- URL detection
- Logistic Regression model

## 📊 Output
- Accuracy score
- Confusion matrix

## 🛠️ Tech Used
- Python
- Scikit-learn
- Pandas

## ▶️ How to Run
1. Install dependencies
2. Run `python main.py`

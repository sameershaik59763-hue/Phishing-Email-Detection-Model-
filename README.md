# Phishing-Email-Detection-Model-

This project builds a Machine Learning model using Scikit-learn to detect whether an email is Phishing or Safe.
The model analyzes:
	•	Email text content
	•	URL presence
	•	Message length

⸻

🎯 Objectives
	•	Train on phishing vs legitimate email dataset
	•	Extract features (text + URLs)
	•	Classify emails accurately
	•	Evaluate using accuracy & confusion matrix

⸻

🧠 Technologies Used
	•	Python
	•	Pandas
	•	Scikit-learn
	•	NumPy
